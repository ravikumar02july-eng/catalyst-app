# Catalyst

A beginner-friendly stock market scanner mobile app built with React Native + Expo.

## Features
- Modern dark trading dashboard
- Watchlist
- Stock scanner
- Search by symbol
- Portfolio summary
- Alerts screen
- Login screen
- Pattern-based signal logic for bullish/bearish stock bias

## Run locally

```bash
npm install
npx expo start
```

Then press:
- `a` for Android emulator
- or scan the QR code on a physical device

## Tech stack
- React Native
- Expo
- TypeScript
- React Navigation
- react-native-chart-kit
